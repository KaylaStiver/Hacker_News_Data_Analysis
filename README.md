# 📊 Hacker News Data Analysis: User Trends in Activity

## 📌 Overview
By analyzing data from user-generated posts, this study identifies trends in popular Hacker News topics to determine whether "Ask Hacker News" or "Show Hacker News" posts are more popular amongst users. 
In addition, peak user activity time frames are identified from raw data.

## ⚙️ Installation & Environment Setup
1. Start Jupyter Lab or Notebook:
   ```bash
   # Clone the repository
    gh repo clone KaylaStiver/Hacker_News_Data_Analysis
   ```
2. Open `hacker_news.ipynb` from the file browser.
3. Run all cells sequentially to load the local data file and reproduce the analysis.
  
## 🗂️ Data Description
The analysis uses `hacker_news.csv` located in the root directory. Key columns include:
* `title`: Title of post.
* `num_comments`: Number of comments per post.
* `created_at`: Date post was created.

## 📄Data Sets
Sourced from Kaggle, for more information please refer to the link below:
* [Hacker News Posts](https://www.kaggle.com/datasets/hacker-news/hacker-news-posts)
